# Flujo de publicación del proyecto

- El repositorio canónico es `https://github.com/ablanco66-arch/Quiniela.git`, rama `main`.
- Después de cada cambio solicitado, valida la compilación y registra un commit intencional.
- Envía ese mismo commit a la rama `main` de GitHub antes de publicarlo.
- Publica exactamente el mismo commit en el proyecto de Sites indicado por `.openai/hosting.json`.
- Confirma que el despliegue de Sites terminó correctamente antes de dar el trabajo por concluido.
- No incluyas archivos de credenciales, secretos, variables locales ni artefactos temporales en GitHub.
